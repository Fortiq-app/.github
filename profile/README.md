# Fortiq

Fortiq is an independent competitive Fortnite analytics platform. Players and coaches can look up Cup leaderboards and player placements, compare landing routes on the 32K island map, and review completed matches with replay analysis and AI coaching.

- [Cup leaderboards and tournament stats](https://fortiq.app/cups)
- [Fortnite 43.10 map and named locations](https://fortiq.app/fortnite-43-10-map/)
- [Dropmap generator](https://fortiq.app/fortnite-dropmap-generator.html)
- [Example replay report](https://fortiq.app/r/demo)
